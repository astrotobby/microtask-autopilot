Platform connections

Sign in yourself in a dedicated browser window per platform. Your passwords and sessions stay in that browser's own encrypted store; this program never sees, stores or sends them, and never bypasses CAPTCHA, MFA, identity checks or KYC. "Connected" means you confirmed it; it is not verified automatically. What the program may do in an account depends on the platform's verified terms (the "permitted automation level" column).

API keys (only for platforms that issue one for a documented API) are stored with py -3 microtask_monitor/connect.py set-key <platform> <name> in Windows Credential Manager, never in this page.
