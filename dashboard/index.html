Whop Workforce

Bounties are read through Whop's documented API with your own OAuth authorization (read-only scope bounty:basic:read). This program never opens or scrapes whop.com, never likes, follows, comments or posts for you, never starts or submits an attempt, and never withdraws money. You do those on Whop; the result is followed here from the API.

Platform connections

Sign in yourself in a dedicated browser window per platform. Your passwords and sessions stay in that browser's own encrypted store; this program never sees, stores or sends them, and never bypasses CAPTCHA, MFA, identity checks or KYC. "Verified" means the platform's documented API answered your authorization. "Confirmed by you" means you said you are signed in; that cannot be checked automatically where a platform's terms do not allow automated access. What the program may do in an account depends on the platform's verified terms (the "permitted automation level" column).

Platform permission registry

From each platform's own terms and documentation, with the date read. "Not verified" means exactly that.

API keys (only for platforms that issue one for a documented API) are stored with py -3 microtask_monitor/connect.py set-key <platform> <name> in Windows Credential Manager, never in this page.
